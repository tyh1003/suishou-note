# 隨手記 Suishou Note

一款簡單、溫暖且方便使用的 Android 隨手記事 App。

「隨手記」希望提供一個舒服的空間，讓使用者可以快速記錄 **開發靈感、文章創作與每日心情**。
整體以簡潔操作、舒適配色與快速記錄為主要設計方向。

## ✨ 功能特色

### 💡 開發 / 專案發想

用來記錄開發想法、Side Project、功能構想與技術筆記。

每張卡片包含：

* **名稱**：專案、功能或想法名稱
* **簡述**：記錄開發方向、工具、技術等資訊
* **詳述**：記錄完整的開發想法
* 詳述預設採用列點式撰寫
* 提供「插入列點（•）」快捷功能
* 卡片支援展開與縮起
* 縮起後僅保留名稱與簡單資訊

### ✍️ 文章

用來保存文章、小說、詩詞或其他文字創作。

每張卡片包含：

* **名稱**

  * 可以自行輸入
  * 留空時自動使用當日日期作為名稱
* **文章類型**

  * 詩
  * 短文
  * 小說
  * 英文
  * 中文
  * ✏️ 自訂
* **詳述**

  * 自由輸入文章內容
  * 不限制文章長度與格式
  * 顯示即時字數統計
* 支援卡片展開與縮起



---

### 📖 日記

簡單記錄每天發生的事情與當下的心情。

每篇日記包含：

* **日期**

  * 自動帶入當日日期與星期
* **心情**

  * 😊 開心
  * 😢 難過
  * 😌 平靜放鬆
  * 🤯 複雜
  * ⚡ 充滿活力
  * ✏️ 自訂
* **詳述**

  * 自由記錄當天發生的事情、想法與感受
* 支援卡片展開與縮起

## ＋ 快速新增

右下角提供「＋ 快速新增」按鈕。

快速新增統一使用簡單的三欄格式：

**名稱 ＋ 日期 ＋ 詳述**

適合臨時出現想法時快速記錄，不需要先選擇完整的分類與設定。

---

## 🎨 UI 設計

整體採用 **Warm Earth & Apricot Theme**。

主要使用：

* 奶茶杏色
* 柔和膚色
* 大地陶土色
* 蜜橘色
* 暖白色

介面大量使用圓角、柔和留白與卡片式設計，降低視覺負擔。

三個主要分類會使用不同的柔和背景色與主題色，讓使用者可以快速辨識目前所在的記事空間。

設計原則：

> **舒服、簡潔、方便、快速記錄。**

---

## 🗂️ 卡片功能

所有記事以卡片形式呈現，並支援：

* 展開 / 縮起
* 全部展開 / 全部縮起
* 編輯
* 刪除
* 複製
* 卡片置頂
* 關鍵字即時搜尋

讓內容多起來之後仍然可以快速整理與尋找。

---

## 💾 資料儲存

使用 **Android Jetpack Room** 建立本地資料庫。

開發靈感、文章、日記與快速新增內容皆儲存在裝置本機，不需要網路也能正常使用。

## 📱 專案目標

「隨手記」不是複雜的筆記管理工具，而是一個打開後就能開始寫的簡單記事空間。

不論是一個突然想到的 App 功能、一小段文章、一個 Side Project 點子，或只是今天的心情，都可以快速留下來。

**想到就記，寫完就走。**
